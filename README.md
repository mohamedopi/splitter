# قصّاص الفهرس (PDF Bookmark Splitter)

تطبيق أندرويد يقسّم ملف PDF عند كل bookmark ويسمّي كل ملف باسمه. يعمل بدون إنترنت،
وواجهته بيضاء أو سوداء حسب وضع النظام.

## مكان الحفظ
- **بجانب الملف الأصلي**: يعمل عندما يكون الملف داخل `Download` أو `Documents` (أو مجلد فرعي منهما).
- **مجلد أختاره**: يفتح منتقي المجلدات (يبدأ عند مجلد الملف) في كل مرة.
- في كل ملف جديد يُطلب منك اختيار المكان من جديد، ولا يُحفظ شيء قبل أن تختار.
- خيار «وضع الملفات داخل مجلد جديد» يضع الملفات في مجلد باسم تكتبه.

## بناء الـ APK
1. ارفع محتويات هذا المجلد كما هي إلى مستودع GitHub (تأكد من رفع مجلد `.github`).
2. افتح تبويب **Actions** وانتظر انتهاء «Build APK» (نحو 3 إلى 5 دقائق).
3. حمّل `PdfBookmarkSplitter.apk` من صفحة **Releases** (الإصدار `latest`).
4. على الهاتف افتح الملف واسمح بالتثبيت من المتصفح أو من تطبيق الملفات عند الطلب.

لتحديث التطبيق عدّل `app/src/main/assets/index.html` وارفعه، فيُبنى APK جديد تلقائيًا.

## اللغة / Language
- الواجهة عربية أو إنجليزية تلقائيًا حسب لغة النظام (أي لغة غير العربية تعرض الإنجليزية)، وزر أعلى الصفحة يبدّل اللغة يدويًا.
- اسم التطبيق ورسائل الأخطاء تتبع لغة النظام أيضًا (`res/values` للإنجليزية و`res/values-ar` للعربية).
- The UI follows the system language (Arabic or English); a button at the top switches it manually.

## الـ bookmarks داخل الملفات الناتجة
عند التقسيم عند مستوى معيّن، تُحفظ كل الـ bookmarks الأعمق منه داخل الملف الناتج بنفس تسلسلها.
مثال: التقسيم عند «الكتاب» يُبقي الفصول وعناوينها الفرعية داخل كل كتاب، والتقسيم عند «الفصل» يُبقي العناوين الفرعية داخل كل فصل.
يظهر مفتاح «الاحتفاظ بالـ bookmarks الفرعية» عندما يوجد مستوى أعمق، وهو مفعّل افتراضيًا.

يتطلب أندرويد 10 فأعلى.

## تحديث الواجهة (2026-10)
- تحديث نظام الألوان إلى أزرق هادئ مع خلفيات وبطاقات أوضح، مع دعم الوضع الفاتح والداكن وفق إعدادات النظام.
- تحسين المسافات، والحدود، وحالات التركيز بلوحة المفاتيح، وأحجام مناطق اللمس، وتباين خيارات التقسيم المحددة.
- جعل بطاقة اختيار الملف والنتيجة أكثر وضوحًا، مع الحفاظ على الواجهة العربية والإنجليزية.
- لم تُغيّر خوارزمية قراءة الـ bookmarks أو تقسيم صفحات PDF أو بناء ZIP؛ التعديل المرئي محصور في CSS لتقليل مخاطر التأثير على سلامة الملفات الناتجة.

## التحقق
- اجتازت كتل JavaScript الثلاثة فحص الصياغة باستخدام `node --check`.
- لم يُنفّذ بناء APK محليًا في بيئة التعديل لعدم توفر Gradle وAndroid SDK فيها. يمكن بناء APK باستخدام GitHub Actions كما هو موضح أعلاه.
